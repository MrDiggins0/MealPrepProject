Sprint 1 Goal: A user can log into the app and set up a weekly plan

Table:
Create a Weekly Meal Plan User story: As a student, I want to create a weekly meal plan, so that I can organize what I will eat throughout the week. Testable criteria: The user can select a day of the week and add a meal to it. The user can add meals for multiple days. The meal plan displays meals organized by day. The user can remove or replace a meal from the plan. The meal plan is saved when the user leaves and returns to it. (L)

Search and Filter Recipes User story: As a student, I want to search and filter meal-prep recipes by cost, ingredients, dietary restrictions, and cooking time, so that I can quickly find meals that fit my needs. Testable criteria: The user can search for recipes using a keyword. The user can filter recipes by cost, ingredients, dietary restrictions, and cooking time. The search results only display recipes that match the selected filters. The user can apply multiple filters at the same time. The user can clear filters and return to the full recipe list. (M)

Create User Accounts: As a student, I want to be able to log into the app using an account. (S)
